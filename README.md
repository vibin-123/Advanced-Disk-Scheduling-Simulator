# Advanced-Disk-Scheduling-Simulator
Disk Scheduling Simulator is an interactive desktop application built with Python and Matplotlib that visualizes and compares four classic disk scheduling algorithms: FCFS (First-Come-First-Served), SSTF (Shortest Seek Time First), SCAN, and C-SCAN. It's designed as a learning tool for understanding how an operating system's disk scheduler decides the order in which it services I/O requests to minimize seek time.
Users can input a custom disk size, starting head position, and a queue of I/O requests (or choose from preset patterns like Scattered, Clustered, and Sequential), then run all four algorithms simultaneously. The app renders a seek-path plot for each algorithm, a side-by-side bar chart comparing total seek distance, and a live summary panel showing total seek distance, average seek time per request, and throughput — automatically highlighting the best-performing algorithm for the given input.
The UI features a clean "bright retro" visual theme with a fully responsive layout that auto-detects screen resolution and DPI to scale fonts and widgets accordingly, so it looks consistent on both laptops and external monitors.
This project was built to strengthen practical understanding of Operating Systems concepts around disk I/O scheduling, complementing theoretical coursework with a hands-on, visual simulation.
